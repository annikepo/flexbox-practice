# Flexbox Practice Assignment

This project recreates a Figma design using HTML div elements and CSS Flexbox.

## Project requirements

- Use HTML div elements.
- Use CSS Flexbox for positioning.
- Create the squares layout from the Figma reference.
- Create the circles using div elements and CSS.
- Use a minimum screen height of 100vh.
- Keep margins and padding at a maximum of 20px.
- Avoid absolute positioning.

## Files

- `index.html` contains the page structure.
- `style.css` contains the styling and Flexbox layout.

## Technologies

- HTML
- CSS
- Flexbox
